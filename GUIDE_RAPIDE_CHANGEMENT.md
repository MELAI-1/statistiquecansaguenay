## 🔥 CAS SPÉCIAUX

### **Changement double (même équipe, minute 45)**
```
Minute 45 - FC Lyon :

1️⃣ CHANGEMENT #7 → #12
   45'  CHANGEMENT  FC Lyon  #7 → #12

2️⃣ CHANGEMENT #14 → #18
   45'  CHANGEMENT  FC Lyon  #14 → #18

Résultat journal :
  45'  CHANGEMENT  FC Lyon  #7 → #12
  45'  CHANGEMENT  FC Lyon  #14 → #18
```

### **Changement rapide (player injury)**
```
Minute 32 - Blessure grave :

1️⃣ CHANGEMENT urgent #9 → #17
   32'  CHANGEMENT  FC Lyon  #9 → #17

(Pas besoin de description, c'est clair !)
```

### **Changement avec description optionnelle**
```
Système : Permet d'ajouter du contexte dans le champ "Description"
Exemple : "Blessure à la cheville", "Changement tactique", etc.

Mais PAS OBLIGATOIRE pour les changements !
```

## ✨ AMÉLIORATIONS PAR RAPPORT À AVANT

| Avant | Après |
|-------|-------|
| ❌ Juste un dossard | ✅ Deux dossards (sortant ET entrant) |
| ❌ Format ambigu : "#7" | ✅ Format clair : "#7 → #12" |
| ❌ Impossible de savoir qui remplace qui | ✅ Remplacement clairement visible |
| ❌ Une colonne "Dossard" | ✅ Deux colonnes : "Sortant" et "Entrant" |
| ❌ Données mélangées | ✅ Structure organisée dans Google Sheets |

## 🎓 DIFFÉRENCES AVEC LES AUTRES ACTIONS

### **Action normale (But, Faute, etc.) :**
```
⚽ BUT :
  1. Équipe : FC Lyon
  2. Dossard (joueur) : 7
  3. (Optionnel) Description
  4. Cliquer sur ⚽ BUT
  
Résultat : 45'  BUT  FC Lyon #7
```

### **Action Changement :**
```
🔄 CHANGEMENT :
  1. Équipe : FC Lyon
  2. Dossard qui SORT : 7
  3. Dossard qui ENTRE : 12
  4. Cliquer sur 🔄 CHANGEMENT
  
Résultat : 52'  CHANGEMENT  FC Lyon #7 → #12
```

**Point clé :** Les changements ont une section spéciale avec 2 champs !
